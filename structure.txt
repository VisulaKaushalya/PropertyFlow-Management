PropManager architecture and file structure
===========================================

This repository is a pnpm workspace monorepo. The product is split into a
React frontend, an Express API, shared generated API code, and a shared
Drizzle database package.

Request flow
------------

Browser -> React page -> generated React Query hook (or task/upload fetch)
        -> /api Express route -> Drizzle ORM -> PostgreSQL

The OpenAPI file should be edited before changing generated API request or
response shapes. Run api-spec codegen after editing it. Database changes are
made in lib/db/src/schema and applied with the db push command.

Payment month defaults
----------------------

The frontend uses the tenant lease start day and existing payment months to
suggest the next rent month and due date. The suggestion is editable before
the payment is saved; it is a convenience, not a replacement for accounting
review.
